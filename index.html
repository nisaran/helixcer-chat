Secret setup

In Apps Script → Project Settings → Script Properties, add secrets for each channel. Never put tokens in this form or in GitHub.

WhatsApp channel ID "wa-main":
CHANNEL_WA-MAIN_ACCESS_TOKEN = your token
CHANNEL_WA-MAIN_PHONE_NUMBER_ID = your phone number ID

Generic channel secret prefix "CHANNEL_CUSTOM_API":
CHANNEL_CUSTOM_API_API_TOKEN = your API token
