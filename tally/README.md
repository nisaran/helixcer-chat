# Helixcer Chat for TallyPrime — build 360

https://raw.githubusercontent.com/nisaran/helixcer-chat/cursor/tally-minimal-storage-b545/tally/helixcer-chat.tdl

Title must show **(build 360)**.

## Create

1. Config Name → Template Name → Language
2. **Enter** on Language (or **Alt+F**) to fetch template variables
3. Header section appears only if the template has a header (media or text)
4. Body/button variable rows appear for each template variable (up to 16)
5. Then voucher types → settings → Ctrl+A

Voucher types stay locked until fetch succeeds, so Enter cannot skip past Language without loading maps.
