# Helixcer Chat for TallyPrime

## Load

1. Add `tally/helixcer-chat.tdl` (F1 → TDLs & AddOns) and enable it.
2. Gateway → **Helixcer Chat**.

## API Settings (save only)

1. Enter Workspace ID, Channel ID, API Key (Tab through each field).
2. Enter / Ctrl+A → **Do you want to save?** → Yes.
3. Reopen: IDs stay filled; API Key shows `******`.

Values are written with explicit `SET` from the field contents on save.

## Status

1. Open **Status** (plain screen, like About).
2. Press **Alt+R** to call `GET /api/v1/connection` and show Status / Workspace / Channel message boxes.
